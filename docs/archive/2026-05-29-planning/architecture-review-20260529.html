1. ThreadOwnershipStore (seam)

Files: opencode-provider.js, runtime-provider-router.js, new thread-ownership-store.js

Problem: OpenCode harness keeps threads in class Maps. Restart loses routing. Router cannot reason about ownership without reaching into provider internals.

Solution: One module owns durable ThreadOwnership records. Harnesses report facts; router queries store.

Benefits: High leverage interface (lookup by id). Locality for resume bugs. Tests target store file I/O only.

Before:
Router ──► OpenCodeProvider.threads (Map)
         ──► Codex (implicit)
After:
Router ──► ThreadOwnershipStore
OpenCodeHarness ──► store.upsert()
CodexHarness ──► store.upsert()
Strong
